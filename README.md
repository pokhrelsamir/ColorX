## 📌 Overview

**ColorX** is a simple and modern color palette generator designed for developers, designers, and anyone who needs quick color combinations.

Generate a five-color palette, lock colors you like, regenerate the rest, copy individual HEX values, and save complete palettes directly in your browser.

No account.
No backend.
No database.

Everything runs directly in the browser.

---

## ✨ Features

### 🎨 Random Palette Generation

Generate a new five-color palette instantly with randomly generated HEX colors.

### 🔒 Lock Colors

Lock individual colors that you want to keep while regenerating the remaining colors.

### 📋 Copy HEX Colors

Click any color card to instantly copy its HEX value to your clipboard.

### 📦 Copy Entire Palette

Copy all five HEX values together for convenient use in your projects.

### 💾 Save Palettes

Save your favorite palettes directly to browser LocalStorage.

### 🗑️ Delete Saved Palettes

Remove palettes that you no longer need.

### 🔔 Toast Notifications

Get instant visual feedback when copying, saving, or deleting palettes.

### 📱 Responsive Design

ColorX adapts to desktop, tablet, and mobile screen sizes.

### ⚡ Lightweight

No frameworks, build tools, backend, or external dependencies are required.

# ⚙️ How It Works

## 1. Generate

ColorX generates five random HEX colors.

```text
#6C63FF
#00B894
#0984E3
#FD79A8
#FDCB6E
```

## 2. Lock

Lock any color you want to preserve.

When the palette is regenerated, locked colors remain unchanged.

## 3. Regenerate

Generate a new combination without losing your locked colors.

## 4. Copy

Click a color to copy its HEX value.

You can also copy the entire palette at once.

## 5. Save

Favorite palettes are stored using the browser's LocalStorage API.

Saved palettes remain available after refreshing the page.

# 🧪 Usage

### Generate a palette

Click:

```text
↻ Generate
```

### Lock a color

Click the lock button on a color card.

### Copy a color

Click anywhere on the color card.

### Save a palette

Click:

```text
♡ Save Palette
```

### Copy the entire palette

Click:

```text
⧉ Copy Palette
```

### Delete a saved palette

Click the delete button on a saved palette.
